FastAPI + Polar.sh Integration Guide

A step-by-step production blueprint for integrating Polar.sh Merchant of Record billing, HMAC-SHA256 webhook security, and software license key validation in Python.

Selling digital software or paid APIs globally requires handling sales tax across international jurisdictions. Polar.sh solves this by operating as a Merchant of Record (MoR), calculating and remitting taxes automatically. This tutorial explains how to securely connect Polar with FastAPI.

STEP 1 Verifying Standard Webhook Signatures

Polar signs webhook requests using the Standard Webhooks specification (HMAC-SHA256). Every webhook request includes three required headers:

  • webhook-id: Unique message identifier.
  • webhook-timestamp: UNIX epoch timestamp when the message was sent.
  • webhook-signature: Base64-encoded HMAC-SHA256 signatures prefixed with v1,.

Here is the production implementation from PyLaunchpad:

import base64
import hmac
import hashlib
import time

def verify_polar_webhook(payload: bytes, headers: dict, secret: str) -> bool:
    """Cryptographically verify Polar.sh webhook signature with replay protection."""
    msg_id = headers.get("webhook-id")
    msg_timestamp = headers.get("webhook-timestamp")
    msg_signature = headers.get("webhook-signature")

    if not (msg_id and msg_timestamp and msg_signature):
        return False

    # 1. Enforce 5-minute replay attack tolerance
    try:
        ts = int(msg_timestamp)
        if abs(time.time() - ts) > 300:
            return False
    except ValueError:
        return False

    # 2. Decode Polar webhook secret
    raw_secret = secret.replace("whsec_", "")
    key = base64.b64decode(raw_secret)

    # 3. Compute HMAC-SHA256 over message envelope
    signed_payload = f"{msg_id}.{msg_timestamp}.".encode("utf-8") + payload
    expected_hmac = hmac.new(key, signed_payload, hashlib.sha256).digest()
    expected_sig = base64.b64encode(expected_hmac).decode("utf-8")

    # 4. Timing-safe comparison across signatures
    signatures = [
        s.split(",", 1)[1] if "," in s else s
        for s in msg_signature.split(" ")
    ]
    return any(hmac.compare_digest(expected_sig, s) for s in signatures)

STEP 2 FastAPI Webhook Endpoint Router

Next, mount an async endpoint in FastAPI that receives the raw request body and verifies the signature before processing database transactions: 

from fastapi import APIRouter, Request, HTTPException, status
import json

router = APIRouter(prefix="/api/v1/billing", tags=["Billing"])

@router.post("/webhook")
async def handle_polar_webhook(request: Request):
    payload = await request.body()
    headers = dict(request.headers)

    if not verify_polar_webhook(payload, headers, settings.POLAR_WEBHOOK_SECRET):
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST,
            detail="Invalid webhook signature or timestamp expired",
        )

    event = json.loads(payload.decode("utf-8"))
    event_type = event.get("type")

    if event_type == "order.created":
        order_data = event.get("data", {})
        customer_email = order_data.get("customer", {}).get("email")
        # Fulfill customer order in SQLAlchemy database
        await fulfill_order(customer_email, order_data)

    elif event_type == "subscription.updated":
        # Handle subscription lifecycle
        await update_subscription(event.get("data", {}))

    return {"status": "received"}

STEP 3 License Key Entitlement Engine

If you sell desktop apps, CLI tools, or on-premise software, Polar offers an automated license key benefit. Upon purchase, customers receive a unique key (e.g. PYLP-XXXX-XXXX-XXXX).

Validate license keys on the client or server with Polar's validation endpoint:

import httpx

async def validate_polar_license(key: str, org_id: str) -> bool:
    """Validate customer license key with Polar API."""
    async with httpx.AsyncClient(timeout=10.0) as client:
        r = await client.post(
            "https://api.polar.sh/v1/license-keys/validate",
            json={"key": key.strip(), "organization_id": org_id},
        )
        if r.status_code == 200 and r.json().get("status") == "granted":
            return True
        return False
