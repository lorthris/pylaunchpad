PyLaunchpad Developer Guide

Everything you need to build, test, and deploy production micro-SaaS and paid AI APIs with Python.

Quickstart

PyLaunchpad requires Python 3.10 or higher. Set up your environment in four commands:

# 1. Clone repository git clone https://github.com/lorthris/pylaunchpad.git cd pylaunchpad # 2. Create virtual environment python -m venv venv # On Windows: .\venv\Scripts\Activate.ps1 # On Linux/macOS: source venv/bin/activate # 3. Install dependencies pip install -e . # 4. Start local development server uvicorn pylaunchpad.app:app --reload --port 8000

Open http://localhost:8000 to view the landing page and http://localhost:8000/api/docs for the Swagger API documentation.

Configuration (.env)

All settings use Pydantic v2 Settings. Copy .env.example to .env:

APP_NAME=PyLaunchpad ENVIRONMENT=development DEBUG=true PORT=8000 # Security (generate a 64-character hex key in production) SECRET_KEY=generate_a_secure_production_secret_key_here # Database (SQLite default; PostgreSQL ready) DATABASE_URL=sqlite:///./pylaunchpad.db # Polar.sh Merchant of Record POLAR_ACCESS_TOKEN=polar_at_... POLAR_ORGANIZATION_ID=org_... POLAR_WEBHOOK_SECRET=whsec_... POLAR_ENVIRONMENT=sandbox

Polar.sh MoR Billing Integration

Polar.sh acts as your Merchant of Record, meaning they calculate, collect, and remit global sales tax, EU VAT, and Australian GST on your behalf.

1. Webhook Verification

Incoming webhooks to /api/v1/webhooks/polar verify Standard Webhook / Svix HMAC-SHA256 signatures with 5-minute replay attack tolerance.

2. Handling Orders

When an order.created event arrives, PyLaunchpad automatically retrieves or provisions the user account and stores the purchase record in the database.

Authentication & API Keys

PyLaunchpad provides dual authentication:

  • Bearer JWT: Signed HMAC-SHA256 tokens for browser sessions and dashboards.
  • X-API-Key: High-performance developer API keys formatted as pylp_live_.... Only the SHA-256 hash is stored in the database.

Database Architecture

Powered by SQLAlchemy 2.0. By default, PyLaunchpad runs on local SQLite with zero setup. To switch to PostgreSQL in production, update your connection string:

DATABASE_URL=postgresql://postgres:password@localhost:5432/pylaunchpad

Async Background Task Worker

Avoid heavy infrastructure like Celery or Redis for simple micro-SaaS workloads. PyLaunchpad includes an in-process async worker queue:

from pylaunchpad.tasks.worker import task_worker async def send_welcome_email(email: str): # Asynchronous email or AI job logic pass # Enqueue without blocking the HTTP request await task_worker.enqueue(send_welcome_email, user.email)

Docker & Caddy HTTPS Deployment

PyLaunchpad includes a hardened multi-stage Dockerfile and turnkey Compose configuration with Caddy:

# Start application and Caddy with automatic TLS docker compose up -d --build
